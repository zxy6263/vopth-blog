## 二、我们收集哪些信息

当您访问本站页面时，服务器会记录一条访问日志，包含以下字段：

| 字段 | 具体内容 | 是否属于个人信息 |
| --- | --- | --- |
| 访问时间 | 精确到秒的时间戳 | 否 |
| 访问路径 | 您打开的具体页面地址 | 否 |
| **IP 地址** | 您的网络地址（原样存储） | **是** |
| 归属地 | 国家 / 省份 / 城市 | **是**（与 IP 关联时） |
| 网络运营商 | 自治系统号（ASN）及运营商名称 | **是**（与 IP 关联时） |
| 浏览器标识 | User-Agent 字符串（截断至 200 字符） | **是**（可能含设备与系统信息） |
| 来源页面 | 您从哪个链接进入本站（Referer） | 可能属于 |
| 边缘节点 | 您接入的 Cloudflare 机房代码 | 否 |

### 我们不收集的信息

```
· 姓名、手机号码、身份证件号码
· 账号、密码（本站不提供注册与登录功能）

```

## 三、处理目的与依据

本站处理上述信息的目的限于以下三项：

```
1. 统计分析
   了解访问量、访问趋势及各文章的阅读情况，用于评估内容价值。

2. 可用性评估
   通过归属地、运营商及接入节点数据，判断本站（托管于境外）
   在中国境内的实际访问质量。

3. 安全防护
   识别并排除自动化爬虫及监控探针，以保证统计数据的准确性。
```

**依据《中华人民共和国个人信息保护法》**，本站的处理行为说明如下：

```
本站不设账号体系，也不要求您提交任何信息。
您对本站的访问是您主动发起的行为。

本站的处理行为遵循该法第一章确立的原则：

  第五条  合法、正当、必要、诚信
          —— 本站不设商业化目的，不转售数据
  第六条  目的明确、合理，与处理目的直接相关，
          采取对个人权益影响最小的方式
          —— 仅记录必要字段、保留 90 日、不作画像
  第七条  处理规则公开透明
          —— 即本政策
  第十七条 以显著方式、清晰易懂的语言真实、准确、完整地告知
          —— 即本政策的第二节
```

⚠️ **需要明确说明的一点：本站不主张以"取得您的同意"作为处理依据**
（《个人信息保护法》第十三条第一项），因为本站不设同意流程，
无法取得符合该法要求的单独同意。

**本站的实际立场是：** 上述处理属于个人非经营性网站的常规访问日志记录，
范围极窄、目的单一、期限很短，且已通过本政策充分公开。**如您对此有异议，
可依本政策第七节行使删除或撤回的权利。**

**本站不基于上述信息进行用户画像、个性化推荐或任何形式的自动化决策。**

## 四、存储与保留期限

```
存储位置    Cloudflare D1（SQLite 数据库服务）
保留期限    90 日，自记录生成之日起算
删除方式    由定时任务自动删除，不作人工干预
```

《个人信息保护法》第十九条规定，个人信息的保存期限应当为实现处理目的所必需的
最短时间。本站的保留期限设定为 90 日，用于覆盖一个完整季度的统计周期，
逾期记录将被自动清除。

**访问权限**：上述数据仅站主本人可经密码验证后访问，不对任何第三方开放。

确需向中华人民共和国境外提供个人信息的，应当具备该条所列条件之一。
本站的实际情况为：

```
· 本站为个人非经营性网站，不构成"关键信息基础设施运营者"，
  亦未处理达到国家网信部门规定数量的个人信息；
· 本站已在能力范围内采取对个人权益影响最小的方式
  （仅记录必要字段、限制保留期限、不进行画像分析）；
· 跨境传输是本站采用境外托管服务的必然结果，
  且已在本政策中向您明确告知。
```

**若您不同意上述跨境传输安排，请停止使用本站。**
