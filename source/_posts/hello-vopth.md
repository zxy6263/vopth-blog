这个域名买了有一阵子，一直挂在注册商那里吃灰。原因也很简单：一想到要买服务器、装环境、配 Nginx、申请证书、还要担心续费和被打，写博客这件事就变得毫无吸引力了。

后来想通了 —— **写博客最贵的是「开始写」这件事，不是服务器。**

所以这次换了个思路：不买服务器，站点全部是纯静态文件，托管在 Cloudflare 的全球网络上，域名还是我自己的。

<!-- more -->

## 现在这套东西是什么

- **域名**：`vopth.xyz`，在阿里云注册的
- **托管**：Cloudflare Pages（免费套餐，无限带宽，自带 HTTPS 证书）
- **生成器**：Hexo —— 我只需要写 Markdown，它负责生成 HTML
- **主题**：Butterfly

整个链路是这样：

```
我写 Markdown  →  git push  →  Cloudflare 自动构建  →  全世界的 CDN 节点  →  你看到的页面
```

没有服务器，没有运维，没有半夜被告警叫醒。构建和分发都在 Cloudflare 那边完成，我这边只需要一个能联网的编辑器和 Git。

## 为什么不买服务器

认真算过一笔账：

| | 买服务器 | 静态托管 |
| --- | --- | --- |
| 费用 | 每年几十到几百，还可能被续费刺客 | 0 元 |
| 备案 | 国内服务器必须备案 | 不需要 |
| 运维 | 系统更新、Nginx、证书续期、防攻击 | 全托管 |
| 速度 | 单机房，异地访问慢 | 全球 CDN 边缘节点 |
| 挂了怎么办 | 自己爬起来修 | 平台负责 |

个人博客就是个「写给未来的自己 + 顺便给别人看」的东西，它的流量模型是**读多写极少**，而且内容几乎是永久不变的。这种场景用动态服务器去扛，本身就是巨大的浪费 —— 静态文件 + CDN 才是正解。

## 关于这个博客会写什么

大致会分成几类：

- **技术笔记** —— 踩过的坑、读过的源码、想明白的原理。写下来主要是为了防止自己第二次踩同一个坑。
- **折腾记录** —— 自建服务、小工具、一些没什么用但很好玩的东西。
- **随笔** —— 生活里的一些片段。技术上写不动的时候，总得有点别的。

## 一些承诺

1. **会一直写下去。** 很多个人博客死在第三篇，我尽量不。
2. **不写水文。** 宁可一个月一篇，也不凑数。
3. **不用 AI 糊文章。** 你可以用 AI 帮忙，但别让 AI 替你思考。
